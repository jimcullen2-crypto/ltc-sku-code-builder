# SKU code builder

This tool builds product SKU codes using only our agreed options — material, license, character, product type, size, and so on. It stops anyone from typing in a made-up code, so every SKU stays consistent.

## Opening it

**Click this link:** *[paste your GitHub Pages link here, e.g. https://your-username.github.io/sku-code-builder/]*

It opens straight in your browser — no login, no download, no app to install. Works on a phone, tablet, or computer.

**Tip:** bookmark it, or add it to your home screen (see below), so you don't have to find the link every time.

## Building a SKU

1. Fill in each dropdown from left to right — **Material**, **Coating**, **License**, **Character / design**, **Product type**, **Size / format**.
   - Character / design only shows once you've picked a License — it only lists the characters that belong to that license.
   - Coating switches off automatically for materials that don't use it.
2. Your SKU code builds itself at the bottom of the box as you go.
3. Add a **Product description** (e.g. "Moomintroll charm bracelet, sterling silver") — this helps make sense of the export later.
4. Click **Add to list**. This button only lights up once all the required fields (marked with a red `*`) are filled in.
5. Repeat for every SKU you need to create in that session — they'll all build up in the table below.

## Getting your list out

At the bottom of the page:

- **Export CSV** or **Export Excel** — downloads a spreadsheet of everything you've added, straight to your Downloads folder.
- **Email export** — opens your email app with the list typed into the body of a new email. This is handy for a quick check, but it won't attach a proper spreadsheet — for that, use Export Excel above and attach the downloaded file to your email yourself.

Your list only lives in that browser tab for that session — closing the tab clears it, so export before you go.

## Adding it to your phone or tablet home screen (optional)

**iPhone / iPad:**
1. Open the link in Safari
2. Tap the **Share** icon (square with an arrow)
3. Tap **Add to Home Screen**

**Android:**
1. Open the link in Chrome
2. Tap the **⋮** menu (top right)
3. Tap **Add to Home screen**

It'll then sit on your home screen like any other app icon.
