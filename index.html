Building a SKU

  1. Fill in each dropdown left to right — Material, Coating, License, Character/design, Product type, Size/Quantity, Material/Finish.
  2. Character/design only appears once you've picked a License, and only shows that license's own options.
  3. Add a product description, then click Add to list. It only lights up once the required fields (marked *) are filled in.
  4. Repeat for every SKU you need — they all build up in the table below.

Getting your list out

  • Export CSV / Export Excel — downloads a spreadsheet of everything added, straight to Downloads.
  • Email export — opens your email app with the list in the body. For a real spreadsheet attachment, download the Excel file and attach it yourself.
  • Your list only lasts for this browser tab — closing it clears the list, so export before you go.

Add to your home screen

iPhone / iPad: open in Safari → Share icon → Add to Home Screen.
Android: open in Chrome → ⋮ menu → Add to Home screen.
